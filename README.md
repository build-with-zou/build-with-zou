## 🔭 What I'm Working On

At SJTU's MVIG Lab, I'm exploring force feedback and how force information might be incorporated into vision-language-action (VLA) models. This work has led me to ask how an agent can use both visual and physical feedback to choose its next action.

---

## 🧠 Technical Interests

- **Embodied AI and robot learning:** How should an agent combine what it sees, feels, and predicts when choosing an action? I'm reading about imitation learning and world models to understand different ways of connecting perception with action.
- **Computer vision and generative models:** What changes as visual data becomes representations of objects, scenes, and language? I'm exploring that path alongside variational autoencoders (VAEs) and diffusion models, which approach data representation and generation in different ways.
- **Learning algorithms and AI agents:** How can a system learn from interaction and adapt when its environment changes? This draws me to reinforcement learning, alternative deep learning approaches, and AI agents.
- **Computer systems and software:** I like understanding the layers beneath a working system. Building a CPU from logic gates, making interactive tools and games, and learning web development let me explore those layers from different directions.
